## About me

Hi, I'm **Bruna**, a Systems Engineering graduate from Bolivia 🇧🇴 with a strong interest in building software that is useful, thoughtful, and truly impactful.

I enjoy turning ideas into practical products, learning by doing, and collaborating with people who care about technology as a tool for real change. My focus sits between web development, backend systems, product thinking, and creating experiences that balance usability with solid engineering.

- 💻 **Engineering:** backend services, APIs, scalable web architecture
- 🤖 **AI & experimentation:** exploring practical intelligence for meaningful workflows
- 🌱 **Growth mindset:** learning continuously and shipping with clarity
- 🌟 **Leadership:** building inclusive, collaborative tech communities
- 💬 **Open to:** software projects, collaboration, and tech conversations with purpose
